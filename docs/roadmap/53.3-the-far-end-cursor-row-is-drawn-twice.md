# 53.3 — In far-end line mode, the cursor's row is drawn twice.

Lane: lane-5-look. Board: [../ROADMAP.md](../ROADMAP.md). This file is the entry until a spec absorbs it; the spec's PR deletes it.

**In far-end line mode, the cursor's row is drawn twice.** Spec: none yet → specify first.

Found on 2026-09-23 while testing V2 (PR #72) against PowerShell in far-end line mode, over the
embedded WebDriver.

- **`gh repo create`'s selection list.** After one Down arrow, the buffer showed the list with
  `> Create a new repository on github.com from a template repository` as its second option,
  and the far-end field held the same text, so it appeared again as the last line on screen.
- **After Ctrl+C cancelled `gh`,** the buffer ended with the prompt `PS C:\Users\marlo>`
  followed by an empty output block, and the far-end field held `PS C:\Users\marlo>` too. The
  prompt showed twice, and the caret was drawn at the start of the field's text.

In the other far-end cases measured the same day (`Read-Host`, a choice prompt, idle
prompts), the field held only what the user typed, and nothing was drawn twice.
