# 28.14 — A line submitted with Ctrl+J or Ctrl+O gets no heading.

Lane: keyboard-routing. Board: [../ROADMAP.md](../ROADMAP.md). This file is the entry until a spec absorbs it; the spec's PR deletes it.

Noticed on 2026-09-25 while working V2.5 (53.5), from the code and from readline's documented
bindings, not from a measurement.

- In far-end line mode, the pump treats a key as submitting a line only when it is Enter: that is
  where it reads the line from the anchor, opens a block headed by it, and waits for the prompt.
- In readline, Ctrl+J is `accept-line` as Enter is, and Ctrl+O is `operate-and-get-next`, which
  also runs the line. Bash, and zsh's line editor, accept a line on Ctrl+J too.
- Not yet measured: what a real bash under WSL sends back for either key, and what the buffer and
  the reader then show.
