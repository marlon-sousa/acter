# 53.4. After a program is stopped with Ctrl+C, the prompt stands alone

Lane 5, the look.

Found on 2026-09-24 while checking V2.3 against PowerShell 5.1 (PSReadLine off), in far-end line mode, on the V2.3 branch and on main alike.

- Run `gh repo create`, press Down Arrow once, then Ctrl+C. gh exits, and the buffer holds the returning prompt followed by an empty block with no heading.
- Type `echo after` and press Enter. The new block's heading comes after the empty block, so the prompt is not followed by a heading, is not floated, and is drawn alone on its line, with `echo after` on the line below.
- Measured through the embedded WebDriver: the last children of `#results` were `P.prompt`, then an empty `DIV.response`, then `H2: echo after`.
- NVDA 2026.1.1 is unaffected: after the Ctrl+C it said "command failed, exit code 2", then "PS C:\Users\marlo>", and the far-end field read blank.
